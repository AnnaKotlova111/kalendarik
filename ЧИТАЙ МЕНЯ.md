# Календарик

Личный календарь на месяц: крупные ячейки, категории с цветами, значки, время и
заметка прямо в клетке, плюс поездки, которые закрашивают все свои дни.

Работает без интернета. Все записи хранятся только в том устройстве, где ты их
делаешь, и никуда не отправляются.

## Что в папке

| Файл | Зачем |
|---|---|
| `index.html` | Само приложение: разметка, оформление и вся логика |
| `ЧИТАЙ МЕНЯ.md` | Этот файл |
| `manifest.webmanifest` | Название и иконка, когда приложение стоит на главном экране |
| `sw.js` | Офлайн-кэш: скачивает приложение в телефон, чтобы работало без сети |
| `icon-180.png`, `icon-192.png`, `icon-512.png` | Иконки |

Все файлы должны лежать рядом — приложение ищет их в своей папке.

## Про уведомления

Само приложение прислать уведомление, когда оно закрыто, не может — Apple не даёт
сайтам такой возможности, и никакие настройки это не обходят.

Поэтому сделано иначе: если у записи указано время и выбрано напоминание, под ней
появляется кнопка **«Напомнить в Календаре iPhone»**. Она отдаёт событие
стандартному Календарю телефона вместе с будильником («за 30 минут»), и дальше
уведомление в нужную минуту присылает уже сам айфон.

Настоящие уведомления внутри самого приложения возможны только двумя путями:
поднять постоянно работающий сервер рассылки push-сообщений (платно, и телефон
должен быть в сети) либо собрать нативное приложение через Apple Developer
Program (99 $ в год).

## Как поставить на iPhone

1. Выложить папку на любой бесплатный хостинг статических сайтов
   (GitHub Pages, Netlify, Vercel, Cloudflare Pages). Нужен адрес на `https://` —
   без него iPhone не сможет сохранить приложение для работы офлайн.
2. Открыть полученную ссылку в **Safari** на iPhone (именно в Safari — Chrome на
   iOS так не умеет).
3. Нажать кнопку «Поделиться» внизу экрана → пролистать до **«На экран „Домой“»** → «Добавить».
4. На главном экране появится иконка. Дальше интернет не нужен.

## Как посмотреть на компьютере

В папке с файлами выполнить:

```
python -m http.server 8123
```

и открыть http://127.0.0.1:8123 в браузере.

Просто двойным щелчком по `index.html` тоже откроется, но офлайн-кэш при этом не
включится — браузер запрещает его для файлов с диска.

## Про сохранность записей

Записи лежат в хранилище браузера (`localStorage`). Они переживают перезагрузку
телефона и обновление приложения, но пропадут, если очистить данные сайта в
Safari или удалить приложение с главного экрана.

Поэтому в настройках есть **«Сохранить копию в файл»** — получается файл
`kalendarik-ГГГГ-ММ-ДД.json`. Его можно закинуть в Файлы или почту, а потом
восстановить через «Загрузить копию из файла». Стоит делать это раз в месяц.

Синхронизации между устройствами нет: календарь на телефоне и календарь на
компьютере — два разных календаря. Перенести записи можно только файлом копии.

## Как обновлять приложение

Если поменять `index.html`, телефон подтянет новую версию не сразу: сначала
покажет сохранённую копию, а свежую скачает в фоне и применит при следующем
открытии. Чтобы изменения приезжали наверняка, удобно поднимать номер версии
кэша в `sw.js` — строка `var CACHE = 'kalendarik-v1';` (сделать `v2`, `v3` и так далее).
